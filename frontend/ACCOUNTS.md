# v4：账号登录、超级管理员与普通管理员权限

## 查看页面

直接打开 `frontend/index.html`（或下载的 v4 HTML）。首次使用先创建超级管理员：填写用户名、至少 12 位密码并确认。没有公开默认密码。以后用账号和密码登录。普通管理员必须由超级管理员在“管理员与权限”页面创建，不能自行注册。

本地演示不上传真实账号：浏览器存储加盐 PBKDF2 密码哈希，不保存明文；会话保存在当前标签页，12 小时过期。账号与权限是离线交互演示，用户可以通过开发者工具修改浏览器数据，因此不能用独立 HTML 保护线上数据。真实网站必须使用服务器鉴权。

## 角色和权限

- 唯一超级管理员拥有全部功能、设置、管理员管理权限。不能通过普通管理员入口停用、降权或重置其密码。超级管理员可以修改自己的密码。
- 超级管理员创建普通管理员、分配功能权限、修改权限、停用／启用账号、重置普通管理员密码。
- 权限按功能划分，不包含按社群隔离：数据总览、社群查看／设置、积分查看／调整／规则设置／导出、邀请查看／撤销／Excel 导出、抽奖查看／管理、公告查看／管理、日志查看。
- 操作权限自动包含对应模块的查看权限。去除查看权限会同时去除同模块的操作权限。
- 普通管理员不能创建、管理其他管理员或授予自己权限；管理员管理权限不在普通管理员可勾选清单中。
- 未分配权限的账号可以登录，但只显示等待授权页面，仍可修改本人密码和退出。
- 修改权限、停用账号或重置密码时，增加账号会话版本；旧会话在下一次请求时被服务器拒绝。独立演示还通过 storage 事件使其他标签页尽快退出。
- 账号操作记录包含时间、操作人、目标账号、权限变更，不能查看密码。后台审计记录只对超级管理员开放。

## 真实 Python 后端

`auth.py` 与 `app.py` 已实现持久化账号、角色、权限校验和会话失效，并不是仅隐藏前端按钮。账号与审计表保存在已有 SQLite 数据库中，原有社群和积分数据不被清除。

首次启动通过私有 `.env` 的 `ADMIN_USERNAME`（默认 `admin`）与 `ADMIN_PASSWORD` 创建唯一超级管理员。`python setup_local.py` 在 `.env` 不存在时生成私有随机密码；不会覆盖已有文件，也不会把密码打印出来。不要把凭据发到聊天或提交到 Git。

超级管理员已存在后，环境中的初始化密码不再覆盖数据库密码；网页修改密码后应使用新密码。会话仅在服务器内存中，服务器重启须重新登录。密码使用独立随机盐和 scrypt，不返回给账号 API。

服务器接口：

- `POST /api/login`：用户名和密码；返回当前用户及 CSRF，设置 HttpOnly、SameSite=Strict 会话 Cookie。
- `GET /api/session`：重新读取账号状态和会话版本，停用或版本不符返回 401。
- `GET /api/admins`、`GET /api/admin-audit`：仅超级管理员。
- `POST /api/admins/create`、`update`、`reset-password`：仅超级管理员；不能新增第二个超级管理员。
- `POST /api/account/password`：登录用户修改本人密码，须验证当前密码，所有旧会话失效。
- `POST /api/settings`：社群字段要求 `groups.manage`，奖励字段要求 `points.configure`；混合修改必须同时拥有两项权限。
- `POST /api/revoke` 要求邀请管理；积分导出要求 `points.export`。快照去除未授权模块的数据和配置，保留共享社群摘要。
- 新公告、抽奖、人工积分接口仍未在 Python 后端实现；已增加对应路由的权限门禁。授权本身不等于补全这些业务，独立前端中的交互仍属演示。

生产仍需配置可信 HTTPS 反向代理和 `COOKIE_SECURE=1`。独立 HTML 的本地账号与服务器账号互相独立，不会自动同步。

## 聊天预览兼容修复

聊天预览可能禁止 `localStorage`、`sessionStorage` 或原生 `crypto.subtle`。修正版会使用明确标注的内存账号／会话存储，以及同参数的 PBKDF2-HMAC-SHA256 兼容实现（120000 次、32 字节输出），不会改用弱哈希或明文密码。兼容实现来自固定版本 @noble/hashes 1.8.0，随单文件一起内嵌，无运行时 CDN 请求；许可证与包完整性记录见 vendor/。

当浏览器禁止持久保存账号时，页面会说明账号仅本次打开有效，关闭后需重新创建；仅禁止会话存储时，重新打开需要再次登录。真实服务器账号与权限校验不受这些离线演示兼容措施影响。

创建按钮现兼容没有 `SubmitEvent.submitter` 的环境，会显示处理中状态及明确的用户名／密码输入错误。回归命令：`python tests/login_compat_smoke.py`。
