# 前端 v3：公告排期与英文 TG 输出

入口为 `frontend/index.html`，打包命令 `python build_preview.py`。页面仍是独立前端，需账号和密码登录，不需要 Bot Token，不会向 Telegram 或 Python 后端发送公告。

## 公告功能

- 内部公告名称可使用中文，只用于后台管理，不附加到 Telegram 消息中。
- 公告正文仅接受英文文本；禁止中文和其他非拉丁文字，不做自动翻译。图片可上传 PNG/JPG/WebP，最大 1MB，必须人工确认图片内可见文字为英文或无文字。系统不做图片 OCR，因此不能自动保证图片内容无中文。
- 图文公告正文最多 1024 个字符；无图片公告最多 4096 个字符，避免后续 Telegram 图片 caption 长度限制。
- 选择目标群组及目标话题；当前话题列表为示例。普通群不携带话题 ID，话题群可选 General 或指定话题。
- 发布方式：立即、指定时间一次、每日重复。每日可设 1–24 次并分别选择时间，也可设开始／结束日期。所有时间均为北京时间 UTC+8，不随浏览器系统时区变化。
- 置顶独立开关；关闭时不会在公告预览中显示置顶条。
- 支持保存草稿、编辑、启用、暂停、恢复、取消、查看英文预览及模拟发布记录。
- 本地运行时维护计划与时段去重键，刷新后不会重复处理同一时段。暂停期间不执行；恢复只执行未来时段。超过 60 秒的过期任务标记错过，不批量补发历史公告。浏览器本地数据清理后不再保留演示任务。

## 定时演示与真实发布

页面保持打开时，每秒检查一次到期任务并生成“已模拟发布”记录；关闭页面后不会继续运行。记录中明确区分已模拟、错过时段和被校验阻止，不将模拟状态标成真实 Telegram 发送成功。

真实无人值守发布尚未实现，不能仅填写 Token 就上线：后续需持久化计划到服务器，增加后台调度 worker、幂等投递、429 限流与失败重试，接入 Bot API `sendMessage`/`sendPhoto` 的 `message_thread_id` 和 `pinChatMessage`，校验群管理员及置顶权限，再做真实群验收。浏览器本地演示不会在后续自动上传到服务器。

## 英文边界

- 后台标签继续为中文，TG 固定回复和预览使用英文：签到、邀请、验证、欢迎及抽奖。
- 自定义欢迎词、公告正文、抽奖活动名与奖励文案会阻止中文／其他非拉丁文字。语言校验按字符脚本进行，不能自动判断一段拉丁文字在语义上是否真是英语，运营人员仍应核对文案。
- 含中文的用户昵称或群名不直接插入 Bot 发送正文，采用英文兜底名称；后台仍显示原有中文名称。图片中的文字须人工确认。
- Python 第一版 Bot 也已改为英文固定文案，并在发送 text/caption/按钮文字前加入同样的校验。已保存的自定义中文欢迎词会停止发送，管理员应改为英文；旧的内置默认中文欢迎模板具有英文兼容处理。
- 此次没有为公告、按月积分或 Lucky Draw 新增真实服务器业务接口。原后端与前端模拟仍相互独立。
