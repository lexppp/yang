# 免费 X 来源验证（尚未启用自动转发）

目标为 `@CoinWOfficial` 的 X 新帖同步到 TG `@coinwofficialchannel`。此文件只记录免费来源检测；不是 TG 频道互转，也不要求付费 API。

运行：

```bash
python3 /home/ubuntu/check_x_feeds.py
```

脚本只读取六个公开 RSS/嵌入候选地址，不读取 `.env`、Token、密码、Cookie、数据库，不调用 Telegram，不重启服务。无需 sudo、第三方 Python 包或 API Key。

检测包括：HTTP 是否成功、XML/公开嵌入数据是否可解析、帖子链接是否对应指定账号、是否有七天内的有效发布时间、是否有图片元数据。网页/登录或验证页面、只有链接无内容、错误账号、时间过旧或未知，都不会误报为可用。XML实体声明和超过2MB的内容不会解析。图片只检查元数据，不下载图片或绕过访问限制。

当前 Codex 检查环境请求全部遭网络代理的 `Tunnel connection failed: 403 Forbidden` 拦截，包括获得临时网络授权后。因此**尚未确认任何免费来源可用，也不能据此判定这些来源全部失效**。网络白名单已保存为环境配置草稿，但尚未应用到当前网络；可先在实际部署的新加坡服务器运行此脚本区分环境限制和来源状态。

分享终端检测结果即可，不要分享配置文件、Token、密码或Cookie。`--json` 可输出结构化报告，账号可用 `--account CoinWOfficial` 指定，超时范围5–30秒。

若有来源返回近期帖子，仍需与 X 原帖对照，并观察下一条真实新帖能否及时进入订阅，再实现自动转发。一次成功不代表公共镜像长期稳定，无法确认来源前不启用 TG 发布。源可能关闭、限流、需要登录，或者只包含部分文字/图片；本脚本不会绕过这些限制。
